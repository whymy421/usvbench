# USVBench 观测契约 v2（人读版规格）

> 代码正本：`tasks/_shared/obs_superset.py`（本文档描述它，不替代它；冲突以代码为准）。
> 测试：`tasks/_shared/test_obs_superset.py`（v1 逐字节回归 + v2 维度表 + 往返一致性）。
> 桥工具：`scripts/obs_bridge.py`（跨任务评测投影 + checkpoint 首层手术）。

## 1. 这是什么

所有任务共用**一个 64 维超集观测布局**。每个任务的"原生观测"是这个超集的一个
**索引子集**（顺序固定、登记在 `NATIVE_LAYOUTS`）。这带来三件事：

1. **一套 API 跑所有任务**：策略结构只依赖超集布局，换任务 = 换 gym id；
2. **跨任务移植**：A 任务的策略可以投影进 B 任务评测（`project()`），
   或做首层手术后热启动（`embed_checkpoint()`）——2026-08-05 首战：
   题A v9 冠军零样本进题B 二段 75.78%/88.28%；
3. **向后不破坏**：v1（0..50 槽）永久冻结；扩展只许追加。

## 2. 槽位表

| 槽 | 名称 | 内容 | 版本 |
|---|---|---|---|
| 0–2 | `nav` | 目标方向 dot / cross、归一化距离 | v1（冻结） |
| 3 | `stage_norm` | 阶段进度 / 到达锁存（跨任务"本段完成"语义） | v1 |
| 4–6 | `lookahead` | 路径跟踪前瞻门几何 | v1 |
| 7–9 | `dock` | 泊位对齐 dot / cross、自身速度（2 m/s 标尺） | v1 |
| 10–45 | `rays` | 36 根雷达（10° 间隔，量程归一化） | v1 |
| 46–49 | `phase` | 任务相位 one-hot（4 段） | v1 |
| 50 | `dwell_fraction` | 驻留时长比（靠泊/站位用） | v1 |
| 51–53 | `kinematics` | 船体系 surge / sway / yaw-rate（v3 三件套，2 m/s 与 yaw 标尺见代码） | **v2 新增** |
| 54–57 | `task_specific` | 任务专属槽（无跨任务语义；占用必须在任务 env 里注释）。已用：站位×浪的海向 dot/cross + 有效波高（54–56） | **v2** |
| 58–63 | `reserved` | **预留全零**。未来任务只准从这里取槽，不准改总长 | **v2** |

`SUPERSET_DIM = 51`（v1 调用方继续可用）；`SUPERSET_DIM_V2 = 64`。

## 3. 登记现状（2026-08-05）

- **47 个现役 gym id 全部登记**原生布局映射（hazard v3–v12 全家 / 强穿 / 环 /
  堡垒 / 砖墙堡垒 / 题B 分段 / 线×避 / 靠泊 / 站位 / 点导航）。
- **2 个显式不支持**：v5 / v10 的可行性池化观测（9 扇区无法如实映射进 36 雷达槽，
  `extract_native` 对它们抛带说明的错误，而不是给错误映射）。

## 4. 规则（凌驾于便利之上）

1. **v1 槽位 0..50 永不重排、永不改语义**（回归测试逐字节锁）。
2. 新通道只许**追加**；新任务的专属需求先用 `task_specific`，不够再从
   `reserved` 申请（申请 = 提 PR 改本文档 + 代码 + 测试三处）。
3. 每个新 gym id 注册时**必须**同步登记 `NATIVE_LAYOUTS`，否则桥和
   统一评测对它失明。
4. 池化类"变形观测"如无法如实映射，登记为不支持——**宁可拒绝，不给错映射**。

## 5. 版本冻结流程（冒烟验收）

按 owner 定的验收标准：挑一个任务在**契约发射模式**（env 直接输出 64 维超集）下
跑通一轮训练 + 评测 → 确认维度、语义、学习曲线正常 → 在本文档和代码里同时打
`FROZEN v2` 标 → 此后新任务一律走契约，老任务不重训（2026-08-04 owner 拍板）。

状态：**未冻结**。阻塞项：env 的超集发射通道目前是 v1（51 维）雏形
（`emit_superset_obs` 开关），64 维通道待接 + 冒烟待跑。

## 6. 桥的用法（速查）

```bash
# 跨任务评测投影（A 策略在 B 环境里跑，无训练）
python scripts/obs_bridge.py --src-ckpt <A冠军.pt> --src-id <A的gym id> \
    --dst-id <B的gym id> --out <手术后.pt>
# 然后用 B 的 id 正常评测手术后的 checkpoint
python scripts/eval_v6_frozen.py --checkpoint <手术后.pt> --task <B的gym id> ...
```

手术内容：策略/价值网首层按共享超集索引重建列（缺的列零初始化）、
输入归一化 running mean/var 同步迁移、Adam 动量矩阵同步迁移。
